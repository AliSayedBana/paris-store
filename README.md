# 🏛️ مول باريس التجاري (Paris Commercial Mall)
### متجر إلكتروني فاخر مبني على WooCommerce & WordPress مع تكامل ذكي لتأكيد الطلبات عبر واتساب

---

## 🌟 نبذة عن المشروع (Project Overview)

**مول باريس التجاري** هو نظام تجارة إلكترونية متكامل مصمم خصيصاً ليجمع بين قسمين تجاريين رئيسيين:
1. **مول باريس للملابس** (ملابس رجالية، ملابس نسائية، أطفال، تخفيضات).
2. **مول باريس للأدوات المنزلية** (أدوات المطبخ، الديكورات، المفروشات، التنظيم، التنظيف).

يتميز المتجر بتجربة مستخدم سريعة وفاخرة بهوية بصرية مميزة، وسلة جانبية تفاعلية (Side Cart Drawer)، وتكامل ذكي مع **واتساب** بحيث يتم حفظ الطلب رسمياً في قاعدة بيانات WooCommerce، ثم يتم توليد رسالة واتساب مفصلة بالكامل وتوجيه العميل فورياً لتأكيد الحجز بنقرة واحدة.

## 🚀 المميزات الرئيسية (Key Features)

- **الهيدر المزدوج الذكي (Dual Mall Navigation):** تبديل سلس وسريع بين "مول باريس للملابس" و"مول باريس للأدوات المنزلية" مع تصنيفات فرعية مخصصة لكل قسم.
- **سلة جانبية تفاعلية (AJAX Side Cart Drawer):** إمكانية فتح السلة، تعديل الكميات، حذف المنتجات، ومعاينة الإجمالي الفوري دون مغادرة الصفحة.
- **نظام تحويل الطلبات إلى واتساب (WhatsApp Orders Integration):**
  - حفظ الطلب كطلب مكتمل بحالة مخصصة (`pwo-awaiting`) في WooCommerce.
  - إرسال تفاصيل الفاتورة، المنتجات، الكميات، الأسعار، بيانات العميل وعنوانه داخل محافظة مصر، مع رابط مباشر لإدارة الطلب للتاجر.
- **صفحة دفع مخصصة للسوق المصري (Custom Egyptian Checkout):**
  - قائمة منسدلة تضم الـ 27 محافظة مصرية مع تكاليف شحن مخصصة.
  - التحقق الصارم من صحة رقم الهاتف المصري (`01xxxxxxxxx`).
- **بطاقات منتجات عصرية (Modern Product Cards):**
  - شبكة عرض متناسقة (`CSS Grid`).
  - شارات خصومات هادئة (`خصم %`) وشارة `جديد`.
  - زر المفضلة التفاعلي (`♡`).
  - عرض السعر الحالي بالأخضر الغابوي مع شطب السعر القديم.
  - زر "+ إضافة إلى السلة" مريح ومتناسق بعرض كامل.
- **تذييل صفحة فاخر (Luxury Footer):**
  - 4 أعمدة رئيسية (عن المول، روابط سريعة، الأقسام، تواصل معنا).
  - 4 شارات ثقة دائرية (التوصيل السريع، التغليف المحكم، الدفع عند الاستلام، الأمان والضمان).
  - أزرار سريعة للواتساب والتواصل الاجتماعي.
- **زر واتساب عائم (Floating WhatsApp):** متواجد دائماً في أسفل الشاشة للتواصل المباشر.

## 🛠️ دليل التثبيت والتشغيل المحلي (Setup Guide)

### 1. المتطلبات (Prerequisites)
- بيئة ووردبريس محلية مثل [LocalWP](https://localwp.com/) أو XAMPP أو Laragon.
- إصدار PHP: `7.4` أو `8.0` أو `8.2+`.
- ووردبريس مثبت عليه إضافة **WooCommerce**.
- قالب **Storefront** الأصلي (كمصدر للقالب الابن).

### 2. تثبيت القالب والإضافات
يمكنك التثبيت بإحدى طريقتين:

#### الطريقة الأولى: النسخ المباشر للمجلدات (الأسرع للمطورين)
1. انسخ مجلد `themes/storefront-paris-child` وضعه في مسار:
   `wp-content/themes/`
2. انسخ الإضافات الثلاث من مجلد `plugins/` وضعها في مسار:
   `wp-content/plugins/`
3. من لوحة تحكم ووردبريس، فعّل قالب **Storefront Child (Paris Store)**، ثم فعّل الإضافات الثلاث.

#### الطريقة الثانية: التثبيت عبر ملفات الـ ZIP من لوحة التحكم
1. اذهب إلى **المظهر (Appearance) > قوالب (Themes) > أضف قالب جديد > رفع قالب** وارفع:
   `storefront-paris-child.zip` ثم اضغط تفعيل.
2. اذهب إلى **إضافات (Plugins) > أضف إضافة جديدة > رفع إضافة** وارفع ملفات الـ ZIP الثلاثة الخاصة بالإضافات ثم فعّلها.

## ⚙️ ضبط الإعدادات الهامة (Configuration)

### 1. رقم الواتساب المخصص لتلقي الطلبات
يمكنك ضبط رقم الهاتف الذي يستقبل إشعارات وطلبات العملاء عبر الذهاب إلى:
**ووردبريس > إعدادات (Settings) > طلبات واتساب باريس**  
أو عبر كود `functions.php`:
```php
update_option('paris_whatsapp_number', '201065968425');
```

### 2. صفحات السلة وإتمام الطلب (Checkout Shortcode)
- تأكد أن صفحة الدفع (Checkout) تحتوي على الشورت كود التقليدي لضمان تكامل حقول محافظات مصر:
  ```text
  [woocommerce_checkout]
  ```
- وتأكد أن صفحة السلة (Cart) تحتوي على:
  ```text
  [woocommerce_cart]
  ```

## 👥 العمل الجماعي ودعوة الفريق (Team Collaboration)

إذا كنت ترغب في دعوة أصدقائك للمساهمة في هذا المشروع:
1. اذهب إلى صفحة المستودع على **GitHub**.
2. اضغط على **Settings** في الشريط العلوي للمستودع.
3. اختر من القائمة الجانبية **Collaborators** ثم اضغط **Add people**.
4. اكتب اسم المستخدم (Username) أو البريد الإلكتروني الخاص بصديقك وأرسل له الدعوة.
5. يمكن لأي عضو بعد قبول الدعوة عمل استنساخ للمشروع (Clone) والبدء في التطوير مباشرة:
   ```bash
   git clone <REPO_URL>
   ```
