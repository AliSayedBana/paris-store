🔗 **رابط المستودع على GitHub:** [https://github.com/AliSayedBana/paris-store](https://github.com/AliSayedBana/paris-store)

## 🌟 نبذة عن المشروع (Project Overview)

**مول باريس التجاري** هو نظام تجارة إلكترونية متكامل مصمم خصيصاً ليجمع بين قسمين تجاريين رئيسيين:
1. **مول باريس للملابس** (ملابس رجالية، ملابس نسائية، أطفال، تخفيضات).
2. **مول باريس للأدوات المنزلية** (أدوات المطبخ، الديكورات، المفروشات، التنظيم، التنظيف).

يتميز المتجر بتجربة مستخدم سريعة وفاخرة بهوية بصرية مميزة، وسلة جانبية تفاعلية (Side Cart Drawer)، وتكامل ذكي مع **واتساب** بحيث يتم حفظ الطلب رسمياً في قاعدة بيانات WooCommerce، ثم يتم توليد رسالة واتساب مفصلة بالكامل وتوجيه العميل فورياً لتأكيد الحجز بنقرة واحدة مع دعم تقسيم الطلبات بين قسم الملابس والأدوات تلقائياً.

## 🚀 المميزات الرئيسية (Key Features)

- **الهيدر المزدوج الذكي (Dual Mall Navigation):** تبديل سلس وسريع بين "مول باريس للملابس" و"مول باريس للأدوات المنزلية" مع تصنيفات فرعية مخصصة لكل قسم.
- **سلة تسوق ذكية مع اختيار منتجات التأكيد (Smart Cart Selection):** إمكانية تحديد عناصر معينة من السلة لإتمام شرائها والاحتفاظ بباقي المنتجات لحين التأكيد.
- **نظام تحويل الطلبات إلى واتساب (WhatsApp Orders Integration):**
  - حفظ الطلب كطلب مكتمل بحالة مخصصة (`pwo-awaiting`) في WooCommerce.
  - إرسال تفاصيل الفاتورة، المنتجات، الكميات، الأسعار، بيانات العميل وعنوانه داخل محافظة مصر، مع رابط مباشر لإدارة الطلب للتاجر.
  - دعم التوجيه التلقائي المباشر في حالة الطلب من قسم واحد، وعرض بطاقتي إرسال منفصلتين مع خيارات ذكية في حالة الطلب من القسمين معاً.
- **صفحة دفع مخصصة للسوق المصري (Custom Egyptian Checkout):**
  - قائمة منسدلة تضم الـ 27 محافظة مصرية مع تكاليف شحن مخصصة.
  - التحقق الصارم من صحة رقم الهاتف المصري (`01xxxxxxxxx`).
- **بطاقات منتجات وصفحات فردية عصرية (Modern Product & Single Pages):**
  - صور منتجات استوديو عالية الجودة مطابقة بنسبة 100% لمسمياتها ومواصفاتها.
  - شبكة منتجات ذات صلة تفاعلية مع معرض صور احترافي.
  - شارات خصومات هادئة (`خصم %`) وشارة `جديد`.
  - زر المفضلة التفاعلي (`♡`).
  - عرض السعر الحالي بالأخضر الغابوي مع شطب السعر القديم.
  - زر "+ إضافة إلى السلة" مريح ومتناسق بعرض كامل.

## 🐳 تشغيل المشروع عبر Docker (Recommended)

المستودع مجهز بملف `docker-compose.yml` جاهز، يقوم تلقائياً بإنشاء حاوية ووردبريس وحاوية قاعدة بيانات MariaDB مع استيراد قاعدة البيانات والصور تلقائياً:

```bash
# 1. استنساخ المستودع
git clone https://github.com/AliSayedBana/paris-store.git
cd paris-store

# 2. تشغيل الحاويات
docker compose up -d
```
المتجر سيعمل مباشرة على: `http://localhost:8080` مع تفعيل القالب، والإضافات، وقاعدة البيانات والصور المتطابقة.

## 🛠️ دليل التثبيت اليدوي (LocalWP / XAMPP)

1. **النسخ المباشر للمجلدات:**
   - انقل `themes/storefront-paris-child` إلى `wp-content/themes/`
   - انقل مجلدات `plugins/*` إلى `wp-content/plugins/`
   - انقل `uploads/paris-custom` إلى `wp-content/uploads/paris-custom`
2. **استيراد قاعدة البيانات:**
   - استورد ملف `paris-store-db.sql` عبر phpMyAdmin أو أداة MySQL المرفقة مع LocalWP.
3. فعّل قالب **Storefront** الأصلي وفعّل القالب الابن **Storefront Child (Paris Store)** والإضافات الثلاث.
